# Public Security Rules

[中文](README.md) | [English](README.en.md)

Exclude real Wi-Fi credentials, tokens, keys, certificates, maintainer paths, fixed ports, internal URLs, device identifiers, private IPs, raw logs, builds, generated configuration, firmware backups, private baselines, and any non-allowlisted binary/media asset.

Use explicit placeholders or runtime input for examples. A demo password is not a production-safe default. Users must preview diagnostic bundles; keep only the minimum error class, relative timing, software version, and reproduction data.

The formal vulnerability channel and supported versions are pending S8/S10. No contact address is invented here.
