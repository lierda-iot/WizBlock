# 公开安全规则

[中文](README.md) | [English](README.en.md)

## 禁止进入公开候选

- 真实 Wi-Fi SSID/密码、Token、API key、证书、私钥和未脱敏 `.env`。
- 维护者盘符、用户名、固定串口、临时目录和内部服务地址。
- 真实设备 MAC、IMEI、ICCID、私网地址及可关联个人/设备的日志。
- `build/`、生成 `sdkconfig`、缓存、core dump、固件备份和原始串口日志。
- 私有 `requirements.md`、`design.md`、项目记忆、TODO、Round状态和迁移快照。
- 未进入二进制 allowlist 的库、固件、字体、图片、音频、模型和数据文件。

示例配置只能使用明确占位符或安全的运行时输入；示例密码也必须说明只适用于隔离演示环境，不能伪装为生产安全默认值。

## 诊断信息

上传诊断包前由用户预览。默认只保留错误分类、相对时间、软件版本和最小复现；设备标识、网络配置、绝对路径和无关日志应删除或稳定脱敏。

正式漏洞报告方式和支持版本将在 S8/S10 决定后写入根 `SECURITY.md`；当前没有公开邮箱或工单地址，不虚构接收渠道。
