# 硬件说明

[中文](README.md) | [English](README.en.md)

## 当前公开事实

- 主控：ESP32-S3。
- 核心板：L-AIWFS300 A0；板载 CH340E 提供 USB-UART 下载与日志链路。
- 显示：ST7789V3，物理分辨率 320×240 横屏；LCD SPI、背光和 IO 扩展复位由 `components/laiwfs300` 统一映射。
- 触摸：CST836U，当前按单点触摸能力使用。
- 音频：ES8311 输出、ES7210 输入；TDM 当前事实为 Slot0=MIC1、Slot1=播放回采REF、Slot2=MIC2、Slot3未接。
- 可选能力：BMI260、AIP8563、TF、SP0A39、D0电机板、LTE/CAT1；每个 Example 只初始化自己声明的能力。

公开候选不复制私有原理图、供应商内部资料或未批准素材。引脚和电源事实以 `CODE/components/laiwfs300/include/` 及已批准公开文档为准，`CODE/boards/laiwfs300` 历史草稿不进入候选。

## 连接与安全

- 断电后连接或拆卸板卡；不在电机运行、扬声器大音量或摄像头传输期间热插拔未声明支持的模块。
- 使用稳定电源和数据线。电机、功放和屏幕同时运行时注意电源能力与发热。
- 烧录前确认目标端口和板卡角色；全片擦除会清除设备配置。
- 电机 Example 必须在受控平整区域、有人工监护且周围无障碍物时运行。
- 未完成电池分压和阈值标定前，电量只作趋势/状态显示，不作安全保护量测结论。

## 能力缺失策略

Example README 必须列出必需硬件。必需能力初始化失败时，Example 应明确报错并停止依赖链路；非必需能力可以降级，但不得伪造已启用状态。
