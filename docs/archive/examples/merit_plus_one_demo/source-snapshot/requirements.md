# 功德+1 Demo 归档需求

状态：已从 EX-024 撤销并迁入 EX-032，暂停开发。

## 目标

在适合敲击检测的设备形态中，识别一次壳体单击，显示一次固定图形“功德+1”，并尝试播放一次短木鱼提示音。该功能不得触发 AI、声源定位、运动、网络或其他产品状态变化。

## 已确认行为

1. 传感器输入采用 BMI260 三轴加速度与三轴陀螺仪原始样本；加速度形成冲击候选，陀螺仪和短时变化用于误触抑制。
2. 阈值、候选确认窗口和冷却时间必须集中配置并通过目标板数据标定，不得把归档默认值直接视为正式参数。
3. 每次有效单击显示固定图形“功德+1”并尝试播放一次私有 WAV；固定中文作为图片资源，不引入中文字库。
4. 动画总时长为 800ms，共 7 帧：光点、萌芽、成长、可读、扩展、最大淡出、同尺寸溶解。
5. 气泡采用轻微不对称的粗颗粒像素台阶轮廓、两层半透明黄色光晕和轮廓内高光；文字较大并靠近气泡内沿。
6. 达到最大尺寸后只降低亮度和 alpha，不缩小。
7. 800ms 内连续有效敲击不叠加、不重启或延长当前气泡；后续触发保留计数，并各自尝试播放音效。
8. 离开允许敲击的业务状态时，未完成气泡和提示音必须按产品优先级取消。

## 已知不适用条件

EX-024 的随机电机动作能够完整模拟“快速偏离局部基线并短时回落”的敲击波形。多轮测试未得到可稳定区分随机运动与真实敲击的阈值，因此本需求不再适用于 `xiaozhi_companion_robot_demo`。
